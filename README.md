# I'm Me — App

## Jinsi ya kuiendesha kwenye kompyuta yako (hiari, kwa kujaribu)

```
npm install
npm run dev
```

## Jinsi ya ku-deploy (Vercel — inapendekezwa, bure)

1. Unda akaunti bure kwenye **github.com** (kama huna)
2. Unda "New repository" jipya, liite jina lolote (mfano `imme-app`)
3. Pakia (upload) faili zote za folda hii kwenye repo hiyo (unaweza kutumia "uploading an existing file" kwenye GitHub, buruta faili zote humo)
4. Nenda **vercel.com**, unda akaunti bure kwa kutumia "Continue with GitHub"
5. Bonyeza **"Add New Project"**, chagua repo yako ya `imme-app`
6. Vercel itatambua kiotomatiki kuwa ni mradi wa Vite — usibadilishe chochote
7. Bonyeza **"Deploy"**
8. Baada ya dakika 1-2, utapata anwani ya moja kwa moja (mfano `imme-app.vercel.app`) — hii ndiyo app yako ikiwa "live" duniani kote!

## Baadaye ukitaka kuongeza vipengele (Wallet, WhatsApp, n.k.)

Badilisha faili za code (kwenye GitHub moja kwa moja, au kwenye kompyuta yako kisha "push"), na Vercel itasasisha app yako moja kwa moja kila mara unapohifadhi mabadiliko — hauitaji "deploy" upya kwa mkono.
